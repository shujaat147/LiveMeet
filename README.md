**LiveMeet** is a real-time multilingual communication platform that lets you chat, call, and share files effectively, with built-in automatic translation for both text and images.

---

## 🚀 Features

- 🌐 **Real-Time Multilingual Chat**: Supports 1-on-1 and group chats, with instant translation of messages into your preferred language.
- 🎤 **Voice Calls & Voice Messaging**: High-quality voice calls and voice messages.
- 📤 **Image & File Sharing**: Share images, PDFs, and more.
- 📸 **Image Translation (OCR)**: Translate text found inside images using built-in OCR and translation.
- 🔒 **End-to-End Encryption**: Secure messaging.
- 📱 **Modern Mobile Experience**: Built with a modern UI using React Native.

## 📲 Installation & Running

### **Requirements**
- Node.js >= 16
- Yarn or npm
- Android Studio / Xcode (for local builds)
- Expo CLI

### **Quick Start**

```bash
# Clone this repo
git clone https://github.com/shujaat147/LiveMeet.git
cd LiveMeet

# Install dependencies
npm install

# Start Expo dev server
npx expo prebuild
npx expo run:android
npx expo start -c
